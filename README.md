# The Orbita Lamp — Product Landing Page

A visually striking, highly interactive promotional landing page designed and built for **Orbita Studio** to launch their inaugural product: **The Orbita Lamp**. 

This project translates modern lighting design into an immersive web experience, combining smooth scroll animations, interactive lighting states, and high-performance frontend architecture to drive pre-orders for Batch 01.

---

## ✨ Features & Highlights

* **Interactive Lighting Control:** Live light toggle allowing users to switch between ambient dark and lit states directly on the page.
* **Scroll-Driven Storytelling:** Smooth scroll animations showcasing product mechanics, precision engineering, and premium materials.
* **Pre-Order Conversion Flow:** Optimized hero and call-to-action sections tailored for Batch 01 reservations.
* **Fluid Responsive Design:** Pixel-perfect typography and layout transitions across mobile, tablet, and high-resolution desktop screens.
* **Production-Grade SEO:** Built-in Open Graph protocol, dynamic Twitter cards, and structured metadata for social sharing.

---

## 🛠️ Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **Styling:** CSS Modules / SCSS 
* **Animations:** GSAP / ScrollTrigger / WebGL (Three.js)
